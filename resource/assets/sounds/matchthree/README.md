# Match Three sounds

Five original synthesized glass-marimba cues, with soft attacks and short echo tails.
No sampled or third-party material. Regenerate with `python3 scripts/matchthree-sounds.py`.
16-bit PCM WAV, mono, 44.1 kHz; all clips fit mobile SoundPool limits.
